# pod-tiktok-mod

Android-приложение в стиле TikTok.

## Возможности

* Тёмный интерфейс
* Вертикальная лента видео
* Лайки и профили
* Настройки приложения
* Сборка APK через GitHub Actions

## Требования

* Разработка только через GitHub с Android-телефона
* Без компьютера
* Работа интерфейса без VPN

Доступность онлайн-видео зависит от источника и сетевых ограничений.
